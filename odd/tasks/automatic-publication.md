# Automatic publication

Objective: Cybersecurity editions are collected, generated, checked, saved, and published to the web on `custodes-intellegentiae.exdataveritas.com` on a schedule, with credentials entered once and no per-edition human step. Supersedes the scheduling part of CSP-4 in `odd/tasks/cybersecurity-pulse.md`.
Branch: per work unit from `main`. Delivery: `ask-on-risk`; forecast ~450 authored lines. Test runner: `node --test packages/*/index.test.mjs scripts/*.test.mjs`.

## Specs
- **S1 — No repeated keys or approvals.** User (verbatim): "Me cansa tener que estar poniendo APIKEYs cada vez. Y dar permisos y demas. Espero que cuando se suba la web a Cloudflare en un subdominio mio, no tenga que estar haciendo todo esto de nuevo". Credentials are entered once, by the user, into GitHub secrets scoped to a deployment environment; scheduled runs need no human input.
- **S2 — Editions publish on their own.** User (verbatim): "Que se publiquen solas". No per-edition review. A fail-closed automatic check replaces it: an edition without a summary, with an uncited or URL-less item, or with operator notes is not published, and the site keeps the previous edition.
- **S3 — Nothing private is uploaded.** User (verbatim): "mientras no subas secretos ni llaves, ni informacion mia o de mis dispositivos, todo bien." No secret, key, account identifier, local path, username, hostname, or device detail in the repository, workflow logs, or the published site. Secrets live only in GitHub environment secrets; the Cloudflare account ID is passed as a secret, not committed.
- **S4 — Web on the user's subdomain.** User (verbatim): "el dominio en cloudflare es \"custodes-intellegentiae.exdataveritas.com\"". Serve `web/` as a Cloudflare Workers static-assets site on that custom domain.
- **S5 — Cadence.** Every three calendar days at 12:00 Europe/Madrid across DST (from CSP-4). A run is due when Madrid local time is at or after 12:00 and the last saved edition's Madrid date is at least three days earlier; repeated triggers on the same day do nothing.
- **S6 — Channels.** Web only for now. X Article stays off until the HTTP 403 is resolved; Telegram is not configured.
