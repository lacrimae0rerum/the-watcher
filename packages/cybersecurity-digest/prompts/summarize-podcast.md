# Podcast episode summary

Write in Spanish. Podcasts are not configured in the initial catalog; use this prompt only when an approved RSS source yields an episode.

- Cite the direct episode URL and distinguish a guest's opinion from verified technical evidence.
- Include a specific defensive action only when the transcript supports it. Do not invent a quotation, speaker credentials, affected versions, or mitigation details.
